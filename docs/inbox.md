# 想法收件箱

> 只装「谁在什么场景遇到什么问题」，**不写方案**。
> 改动后跑 `npm run check:inbox`（查：单条 >100 字、总字数 >3000、「不办」条目缺理由、疑似重复）。

## 规则

1. 每条 ≤100 字，只写「谁在什么场景遇到什么问题」
2. **不写方案**——写出来说明已经处理过了，那该去 [`docs/proposals/`](proposals/)
3. 不排序、不排期、不承诺
4. 进「待办」不代表要做，只表示「这确实是个问题」
5. 移到「不办」必须附一句理由，不许默默删掉
6. **AI 只记不办**：AI 不把「待办」分区当任务清单执行；碰到值得记的念头可以主动问用户要不要加入，但不准不经确认就落笔

与 [`todo.md`](todo.md) 的区别：这里**没有方案、也不承诺要做**；有方案的走提案流程。

# 0018. 识图走子 Agent：一次独立的、无工具的模型调用

日期: 2026-10-18
状态: 已接受
代码落点: packages/offscreen-document/src/chat/vision-agent.ts（文件头指针指回本文件）

## 背景

主 Agent 想「看图」时，图不能直接进主对话。

## 决策

识图是**子 Agent**：一次独立的、无工具的模型调用，是主 Agent 想「看图」时唯一的入口。

理由：

- 消息里根本没有图片字节（只有引用），主对话里也无从塞起（见 0019 / 0020）；
- 一次识图只烧一次图 token，而不是此后每一轮都重发一遍——这是整个方案省 token 的根源；
- 它的上下文与主对话隔离：图里问出来的细节只以**文字**回到主对话，不占着上下文窗口养一张图。

## 口径与后果

- 计费：这是**另一次请求**，用量计在它自己的调用上，不属于主 Agent 那一行统计。
- 模型取「当前激活的模型」，意味着它必须本身支持读图——当前模型不支持时，服务端报错，把错误原文原样交回模型（让它如实告诉用户「这个模型看不了图」，而不是编一段「图上好像有…」）。

# 0022. 资源回收：先删会话、再算引用面、失败不阻塞

日期: 2026-10-18
状态: 已接受
代码落点: packages/offscreen-document/src/chat/asset-lifecycle.ts（文件头指针指回本文件）

## 背景

图片按**内容 hash** 存（见 0021，同一张图重复附加只落一份），所以「该不该删」不能按「谁带过它」判断——必须是「删完之后全库还剩谁在引用它」。

## 决策

- 判据只有引用面一处（conversation-store.referencedAssetIds），删除只有资源库一处，本模块只负责把两者接起来。
- **时序刻意：先删会话、再算引用面**。反过来（先算再删）会把「只有这条会话引用的图」与「别的会话也在引用的图」混在一起，得多维护一份引用计数表——而计数表是典型会漂的东西。
- **回收失败不让删会话报错**：会话已经删掉了（用户要的结果已达成），一张留下的图片是垃圾，不是错误；下次删会话时它若仍无人引用会被再收一遍。
- 归属 offscreen-only（要读 lfs）。

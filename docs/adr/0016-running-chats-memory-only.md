# 0016. 进行中的会话只活在 SW 内存，不落库

日期: 2026-10-18
状态: 已接受
代码落点: src/entrypoints/background.ts（runningChats 处 JSDoc 指回本文件）

## 背景

工作台要展示「哪些会话正在生成」，需要 SW 记录进行中的会话（chat:running 登记进来、chat:finished 撤下）。

## 决策

**刻意不落库**：它没有稳定落点——SW 被回收后内存里这份就没了，而库里若留着一条恒为「进行中」的记录，再不会有事件来收尾它，就成了假状态。故只活在内存，工作台问起时把当前快照给它（`sw:runningChats`）。

它同时是「标签页被关 → 中止它的任务」那条路的判据（见 0030）——不在跑就不必惊动 offscreen。

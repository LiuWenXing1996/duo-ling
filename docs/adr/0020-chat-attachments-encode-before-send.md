# 0020. 附件图片：发送前压码落资源库，消息里只留引用

日期: 2026-10-18
状态: 已接受
代码落点: packages/ui/src/lib/chat-attachments.ts（文件头指针指回本文件）

## 决策

对话附件两条路：

- **图片** → 画布重编码成 JPEG，再落到资源库（`/assets/<内容hash>/`，见 0021），消息里只留一份 `data-asset` 引用（形状见 0019）。
  - 为什么压：这张图会被送去识图调用（见 0018），原始截图动辄 1~3MB，不压就是白烧识图 token、白占库。
  - 为什么不进消息：消息 parts 会原样存进会话库、且每轮对话都整段重发——图片一旦作为字节躺在 parts 里，就是存储与 token 的双份开销（见 0019）。
- **文本文件**（.txt / .md / .json / .csv 这类）→ 读成文本拼进正文。没法当文件发（OpenAI 兼容接口不支持任意文件上传），只能进提示词。

## 硬约束

重编码必须在**发出前**完成：资源一旦落库、引用一旦进消息，它就是历史的一部分了，事后再想「换张小的」得连带改引用。

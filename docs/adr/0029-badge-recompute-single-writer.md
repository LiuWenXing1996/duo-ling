# 0029. 角标唯一写口：按登记表重算，不做增量加减

日期: 2026-10-18
状态: 已接受
代码落点: src/entrypoints/background.ts（refreshBadge JSDoc 指回本文件）

## 背景

工具栏角标的数字 = `pageRunsByTab`（page-monitor 的运行登记表）里该标签页的运行集大小——与浮层灵动岛、popup 的页面概览是**同一个数**（三处对不上就是在骗人）。登记表的变化有好几条路：注入登记 / 换文档清零 / 关标签页清除 / 同 uuid 重复广播覆盖。

## 决策

- `refreshBadge` 是**唯一**的角标写入口（数字与感叹号都走这里，谁都不许另开一处 setBadgeText），每次**整体重算**，不做「收到 runstart 时顺手加一」。
- 为什么重算：登记表是唯一真相源，逐条对齐迟早漏一条；整体重算的逻辑只有一个地方要维护，也天然容得下「一轮里表被改了两次」。可用性翻转也接在这条重算上，而不是在翻转回调里直接改角标。
- 引擎不可用 → 全局一个感叹号（「没有授权就没有数可报」，说的是扩展状态不是某页状态）；可用 → 数字 = 该页运行集大小。没有脚本在跑的页不亮，并把**上一轮设过、这一轮不再相关**的页收干净（差集），否则旧数字会一直挂着。恢复可用时把全局感叹号收掉（没设过专属值的标签页回落全局值）。
- 只报数、不分类：什么颜色代表什么状态是要用户记的额外约定，具体是哪些脚本去浮层灵动岛 / popup 看。

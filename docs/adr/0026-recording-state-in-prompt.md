# 0026. 录制状态常驻注入 prompt

日期: 2026-10-18
状态: 已接受
代码落点: packages/offscreen-document/src/chat/system-prompt.ts（录制状态段指回本文件）

## 背景

AI 有读取页面录制内容的工具（tab_record_*），但它不知道目标页有没有在录、录到了什么——盲试一次工具调用是最差路径，还常把「没开录制」和「开了没刷新」误判成同一个原因。

## 决策

chat-host 在开跑前经 SW 取一次本会话所属标签页的录制状态，**常驻注入 prompt**。录制是前向的——「有没有数据」直接决定 AI 该不该走 tab_record_* 这条路。

## 细节

不注入 host（站点名）：录制按标签页划分，目标是「本会话所属的那一页」，不是某个站点——那一页导航到哪里都继续录，喂给模型的也就该是「这一页录到了什么」。

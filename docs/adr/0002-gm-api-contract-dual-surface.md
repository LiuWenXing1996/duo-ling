# 0002. GM 能力契约：对外油猴标准、对内自有桥

日期: 2026-10-18
状态: 已接受
代码落点: packages/shared/src/api-contract.ts（文件头指针指回本文件）

## 背景

脚本侧 GM 包装与后台桥共用一个命令面，需要一个双方（以及防漂移测试）都认的单一契约定义。

## 决策

- **对外面 = 油猴标准**（`GM_*` / `GM.*`），目标是标准油猴脚本可直接粘贴运行。
- **内部面 = 自有桥协议**（`__dl` 信封 + `ApiRequest` 命令名），**保持稳定**：桥仍是「请求-响应 + Port 下行」两条通道，只增命令、不改形状。
- 约束：所有跨桥值必须满足「结构化克隆」（存储层 IndexedDB 同样要求），统一收窄为 Json 类型；函数、类实例、DOM 节点一律不可跨桥。

## 代价与后果（已知差异，速查页与 spec 必须标注，不能让人以为是实现缺陷）

- `GM_xmlhttpRequest` 无流式：`responseType` 不支持 `stream`（TM 的合法值含 stream）；`onprogress` 只给进度字段，不给 TM 那种「带完整 response 的进度对象」。

# 0037. 缩略图缓存：data URL 不 revoke、失败记空串

日期: 2026-10-18
状态: 已接受
代码落点: packages/ui/src/components/ChatPanel.vue（资源缓存 JSDoc 指回本文件）

## 背景

消息里只有资源引用，缩略图每次渲染都得有图——若每次渲染都去取，同一条消息的 N 个缩略图会发 N 次跨进程请求。

## 决策

- 面板内存里维护「资源 id → data URL」缓存（面板活着期间有效），缓存键就是内容 hash，同一张图天然命中同一条。
- **不 revoke**：存的是 data URL（纯字符串），没有 objectURL 那种需要显式释放的句柄。
- 取不到的（资源被清过 / id 写错）**记空串**——同样是「不重复重试」而非反复发请求。

## 代价

查看过的图片会一直占着内存，上限 = 本次面板会话里出现过的不同图片数。

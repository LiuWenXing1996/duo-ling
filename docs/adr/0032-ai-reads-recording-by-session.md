# 0032. AI 读录制：按会话定位标签页，不按当前激活页

日期: 2026-10-18
状态: 已接受
代码落点: src/entrypoints/background.ts（tab_record_* 工具的读侧 JSDoc 指回本文件）

## 背景

录到的采样在 duoling-runtime 的 tab_events，offscreen 拿不到那个库，AI 工具须经 SW 代读。

## 决策

- 参数是**会话 id 而不是站点**：录制按标签页，读也就按标签页——先由 SW 反查「这条会话所属的那一页」（resolveAiTargetTab，与页面快照 / 环境读数同一个判据），再取那一页存续行整根轴里的采样。
- 为什么不用「当前激活页」：AI 在生成中途自己决定要读时用户可能已经切走，按当前激活页读会把别人那页喂给模型。
- `enabled` 只表示「那一页此刻还开着录制」，**不约束能不能读到记录**：关掉开关只撤 recording、不清数据，之前录的照样读得到（否则「录完关掉再看」这条最自然的用法就没法走）。
- 未开录制时也正常返回（enabled:false, count:0）——调用方据此给准确提示，比抛错更好用（「没开录制」和「开了但没刷新」要能分开说）。真正抛错的只有「定位不到那一页」。

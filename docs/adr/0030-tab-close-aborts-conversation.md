# 0030. 标签页被关 → 中止它那条会话的任务

日期: 2026-10-18
状态: 已接受
代码落点: src/entrypoints/background.ts（abortConversationOfClosedTab JSDoc 指回本文件）

## 背景

会话按标签页归属，标签页没了就没人会去看结果、也没处按停止；而任务跑在 offscreen、与页面无关（这是刻意的，见 chat-host），不显式喊停它就会一路跑完、静默消耗 token。

## 决策

- SW 在 `tabs.onRemoved` 里中止该标签页会话正在跑的任务（runningChats 内存表判据，见 0016）。
- 读归属必须在解绑之前——解绑完就不知道这个标签页归哪条会话了。
- 必须挂在常驻的 SW 上：面板没开的时候标签页照样会被关。

## 备选与否决

- 只靠用户侧入口（工作台「会话历史」的生成中标记）：那要用户主动去翻，被动兜底必须自动化。

# 0031. 标签页被关的记录收尾：先盖章、再重算注册，采样不动

日期: 2026-10-18
状态: 已接受
代码落点: src/entrypoints/background.ts（tab 关闭收尾 JSDoc 指回本文件）

## 决策

标签页被关时的顺序：盖上关闭时刻（`noteTabClosed`，没登记过的页不补行）→ 重算录制件注册。**顺序不能反**：注册判据读的就是这一行（未结束 + recording），先算注册会读到还没盖章的旧状态——关掉的若是最后一页在录的，注册集合就该清空，否则录制件会一直全匹配挂在所有站点上。

已录的采样**一条不动**——用户还要在「活动历史」里看、让 AI 读。

与 0030 同一个理由必须挂在常驻的 SW 上：面板没开的时候标签页照样会被关。

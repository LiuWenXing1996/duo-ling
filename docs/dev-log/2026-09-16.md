## 删除 Electron 桌面版归档（`legacy/`）

**决策**：`legacy/` 整目录删除，连同两个只服务它的脚本（`scripts/port-legacy-ui.py` 平移 UI 组件、`scripts/compare-bridge.py` 逐函数对照桥接层）。依据与验收见提案 [`docs/proposals/done/remove-legacy-archive.md`](../proposals/done/remove-legacy-archive.md)。

**依据**：迁移已在 [plugin-migration-plan.md](../plugin-migration-plan.md) 标记完成。删除前逐项核查过：归档不参与构建（`srcDir: 'src'`、tsconfig 不含它、vitest include 收窄、两个 CI workflow 都不引用），无构建 / 测试 / CI / 依赖安装层面的硬引用。唯一硬编码路径在 `port-legacy-ui.py`，而它未接入任何 npm script 与 CI。

**取回旧实现**（归档内容留在 git 历史）：

- 定位删除提交：`git log --full-history --diff-filter=D --all -- legacy/`——本仓走 PR merge commit，不加 `--full-history` 不保证列出
- 取回整棵：`git restore --source=<删除提交>^ -- legacy/`
- 取回单个文件：`git show <删除提交>^:<路径>`
- 删除提交 `45a2540`，父提交 `ecdcd7c`。锚点必须是父提交：更早的提交不含后来才归档进 `legacy/docs/` 的两篇文档。

**坑**：`legacy/components.json` 是**全仓唯一副本**，而 shadcn-vue 工作流（`search` / `add` / `apply`）以它为配置入口。删归档前必须把它迁到仓库根，并把 `tailwind.css` 从 `src/renderer/src/assets/main.css` 改为 `src/assets/main.css`（`aliases` 因 `srcDir: 'src'` 无需改）——否则等于连工具链配置一起删掉。

**门禁换形态**：桥接层那条「逐函数对照桌面版」的纪律，执行器是 `compare-bridge.py`；对照对象删除后，规则改为**逐函数自检四类语义（默认值回退 / 入参守卫 / 先校验后落盘 / 无变化就不做）+ 单测覆盖**，不再依赖外部原文。

**一并清掉的过时内容**：`conventions.md` 的迁移对照表（仍写 `capability-runtime` / `window.cap` / `tools-data`，这些实现早已随工具链路移除）与平移工具用法段、`AGENTS.md` 的两条对照指引、`README.md` 目录树里的归档节点、`skill-management.md` 待装清单里的 `electron-migration`、`tsconfig.json` 的 exclude 项。

**边界**：`legacy/` 中未平移的 UI 不补平——`Tool*` 系列随工具链路作废，`HomePanel` / `DeveloperPanel` 扩展侧无承载。确需平移时按上面的取回姿势整棵恢复后再平。

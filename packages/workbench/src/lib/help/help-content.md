# 哆灵使用说明

哆灵是 AI 用户脚本工坊：说清你要什么，AI 生成用户脚本，注入第三方页面运行。

## 快速上手

扩展有三个入口，各管一段：

| 入口 | 怎么打开 | 用来做什么 |
| --- | --- | --- |
| 网页浮层 | 工具栏图标 →「打开会话」，或在网页上右键 →「打开哆灵对话」 | 和 AI 对话，说清你要的脚本 |
| 工作台标签页 | 浮层顶栏「打开工作台」，或 popup 标题行的图标 | 管理脚本、回看历史、改设置 |
| 工具栏 popup | 点浏览器工具栏上的哆灵图标 | 看当前页面在跑什么，快速跳到别处 |

最短的一条路：

1. 打开网页浮层，描述你想要的页面效果。
2. AI 生成脚本，可以先在对话里看它写成什么样。
3. 到工作台的脚本列表里启用它。
4. 刷新目标网页，脚本开始生效。

## 对话界面

对话界面是挂在网页上的浮层，不常驻，需要时再打开。

![对话浮层：描述需求，AI 走思考与工具流程生成脚本](/help/floatpanel.webp)

- **打开**：点工具栏图标后按「打开会话」，或在网页上右键选「打开哆灵对话」。浮层出现在页面右下角。
- **收起**：浮层顶栏的「收起」把它收回去，页面恢复原样。
- **附件**：输入区可以带图片与文本文件一起发给 AI。
- **点选元素**：要从页面上取某个元素时用点选，比手写选择器省事。
- **模型**：输入区可以切换模型，可用的模型在「设置 → 模型」里配置。

### 会话按标签页归属

一个标签页一条会话，切换标签页就是切换会话。

- 对话界面里没有会话列表，也没有「新建会话」—— 想开一段全新的对话，就开一个新的标签页。
- 没发过消息的标签页不会留下会话，不必担心攒垃圾。
- 想看以前的对话，去工作台的「会话历史」。
- 正被某个开着的标签页使用的会话不能删除。

## 用户脚本

脚本是真正干活的部件，全部在「脚本列表」里管理。

- **新建**：让 AI 在对话里生成，或自己手写一个单文件脚本。
- **编辑**：点列表里的脚本进编辑器，改完保存。
- **启用 / 停用**：列表里的开关。停用的脚本不会注入任何页面。
- **导入**：从 zip 包、本地路径、粘贴源码、链接，四种方式都行。
- **导出**：把脚本导出成 zip 包，便于备份或分享。
- **历史**：每个脚本有自己的改动历史，改坏了能回退到旧版本。
- **生效范围**：脚本在哪些网站生效由它自己的匹配规则决定，在编辑器里能改。

一个脚本大致长这样：

```js
// ==UserScript==
// @name         隐藏广告浮层
// @match        https://example.com/*
// ==/UserScript==

document.querySelectorAll('.ad-float').forEach((el) => el.remove())
```

## 工作台

工作台是独立的标签页，重界面的活都在这里干。

- **脚本列表**：工作台的默认落点，也是最常用的页面。
- **脚本编辑器 / 脚本历史 / 脚本产物**：编辑脚本、回退版本、看脚本生成的文件。
- **会话历史**：回看过去的对话，可以改名、删除。
- **活动历史**：按标签页看每个页面上的脚本运行情况与报错。
- **文件管理**：浏览扩展存下来的文件——脚本源码、git 内部对象、对话里的图片资源（只读）。
- **设置**：模型、通知、外观等。
- **引导**：需要你在浏览器里手动开启的开关，都集中在这一页。

## 工具栏 popup

点浏览器工具栏上的哆灵图标弹出，关掉即消失。

![工具栏 popup：当前页面的活动记录、脚本与对话入口](/help/popup.webp)

- **当前页面**：这一页的活动记录开关、正在跑的脚本与报错、这一页在用的扩展内置件，以及这一页的对话入口。
- **其他页面**：其他打开的网页上各自的脚本与会话，点一行切过去。
- **标题行**：右侧有「设置」与「打开工作台」两个入口，以及当前版本号。

## 权限与开关

有两项开关需要你在浏览器里手动开启，哆灵才有对应能力：

- **运行用户脚本** —— 不开的话脚本不会注入任何页面；新建、编辑、保存都不受影响。
- **读取本地文件** —— 不开的话「从路径导入」读不到本地 zip。

这两项的分步说明与直达入口都在工作台的「引导」页，那里会按你的浏览器与版本给对应步骤。本页不复述 —— 开关状态随时会变，以引导页实时检测的结果为准。

## 常见问题

**脚本没有生效**

先去工作台的「引导」页确认「运行用户脚本」是否已开启；已开启的话，刷新目标网页再看。也可以在「活动历史」里看这一页有没有报错。

**改了脚本没反应**

保存后脚本会重新注入，刷新页面即可。编辑器提示有未保存的改动时，先保存。

**导入导出的文件放在哪**

导出走浏览器的下载目录；导入既可以选择文件，也可以从本地路径读（需要「读取本地文件」开关）。

# 文档规范

> 一句话：内容规则——一个事实一个家、写当前状态不写变更史、字数上限、水文清单、链接。
> 源文档：[docs/doc-standard.md](../../docs/doc-standard.md)

## 现状

- 一个事实一个家：现在怎么做的在 `docs/` 常青篇就地改；为什么这么定进 `dev-log/conventions`；决定不做的进 conventions 已否决表；想法进 inbox；提案进 `proposals/`；今天干啥进 `dev-log/日`；待办进 `todo`（只索引）；踩坑进 `lessons`。
- 写当前状态不写变更史：禁写「原本…现在已移除」/ PR 号 / commit hash；例外 = dev-log 流水与提案流转/决策记录。
- 提案完成后事实沉淀成常青篇（§3）：现状事实抄常青篇改陈述式；设计论证走过提案的留提案不抄第二遍。
- 软性字数上限：todo 4000 / lessons 3000 / inbox 3000 / dev-log 单日 1500；超限按「搬迁→压缩→提额」。
- 水文清单 9 条自查；链接一律仓库内相对路径。

## 待做

- 无（稳定）。

## 不做

- 同一条规则两处出现（保留一处另处链）；状态标注散落正文；手工复述代码清单。

# 脚本 zip 导入导出

> 一句话：分享语义闭环——导出项目 zip、导入尽量导入（只拦原则项），导入恒为停用态。

## 现状

- 已实施（2026-09-17）。`fflate` 已批准落地（唯一新增依赖，~8KB）。
- 格式 v1：`<脚本名>/project.json` + `files/` + `data/`(恒空预留)；不进 zip：bundle / uuid / enabled / 时间戳。
- 导出：列表行 + 全部导出，隐私提示（源码含凭据风险）；零新增协议命令。
- 导入（2026-09-17 修订准入）：只拦原则项（缺 `project.json` / 非合法 JSON / 非对象）；其余兜底放行 + 报告；构建尽力不淘汰；matches 不校验（启用时校验）；uuid 重生成、允许重名、enabled=false。
- 逐脚本独立、不整包回滚；导入成功停列表页弹汇总报告（成功 N / 失败 M + 原因 + 未导入文件）。

## 本文档不包括什么

- 油猴 `==UserScript==` 格式兼容：自有 zip 格式 v1，不互转油猴头。
- 脚本自动更新 / `.meta.js` 检查：分享语义不含自动更新通道。

# 工具链路移除方案

> 一句话：AI 生成工具整条链路已移除，扩展只留用户脚本 + 对话基础设施（已落地 2026-09-14）。
> 源文档：[docs/tool-chain-removal-plan.md](../../docs/tool-chain-removal-plan.md)

## 现状

- 已完成（2026-09-14 Phase 0–4 落地提交）：约 3.3k 纯删 + 5k 手术改动；manifest 权限集合未变，无需 Chrome 重授权。
- 目标态：扩展只留用户脚本链路 + 对话基础设施；工作台从「工具工作区」变「脚本工作台」。
- 三个坑已处理：抽 `idb-fs.ts` 承接共享 lfs 实例；`tool-code-view`→`code-view` 保留；`window-api.ts` 必留只摘 `tool` 命名空间。
- 存量数据（`/tools/*`、`toolPrefs.*`、工具 id 键）原地留置、不清理（惰性字节、不在读路径）；`home` 标签 kind 保留、内容置空待填。

## 本文档不包括什么

- 存量数据清理逻辑 / 按钮（老大定「不管」）。
- `DeveloperPanel`（已删）、workbench 双脚本列表入口简化（本次不动）。

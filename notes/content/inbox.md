# 想法收件箱

> 一句话：只放问题（≤100 字），没有方案、不承诺要做；轻量想法收集。
> 源文档：[docs/inbox.md](../../docs/inbox.md)

## 现状

- 每条 ≤100 字，只写「谁在什么场景遇到什么问题」；不写方案（有方案直接做变更）。
- 不排序 / 不排期 / 不承诺；进待办不代表要做；移「不办」必须附理由，不许默默删。
- AI 只记不办：不把待办当任务清单执行；值得记的念头可问用户要不要加，不经确认不落笔。
- `npm run check:inbox` 体检：单条 >100 字、总字数 >6000、不办条目缺理由、疑似重复（提醒级，不进 CI）。

## 本文档不包括什么

- 在想法里写方案（写出来说明已处理，该直接做变更）；承诺要做；默默删不办条目。

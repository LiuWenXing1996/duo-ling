# 项目约定决策

> 一句话：仍生效的架构约定 + 已否决方案表；改前先读，避免同一问题被重议一遍。
> 源文档：[docs/dev-log/conventions.md](../../docs/dev-log/conventions.md)

## 现状

- 单端架构：只服务浏览器扩展，不抽 `packages/shared` 双端共用层。
- UI 复用：改 UI 先查 `src/components/` 现有实现，禁照界面重写；`window.api` 桥接使组件零改动。
- 手写数据层须逐条自检四类语义（回退 / 守卫 / 先校验后落盘 / 无变化就不做），各补单测；常量表（如 `providers`）逐字段核对。
- 主题跟随系统深浅色，html 不写 `class="dark"`，新增 UI 用主题变量不硬编码颜色。
- `srcDir:'src'` 必须、`publicDir` 显式 `src/public`；生成物/目录让工具自生成（不靠文档提醒人）。
- 已否决方案表：只记没进提案的小决策（保存草稿按钮 / 工具页改造 / 会话工具解耦），重做时移正文。

## 本文档不包括什么

- 双端共用层（单端不需要）；同一否决项记两处（与 proposals/rejected 二选一）。

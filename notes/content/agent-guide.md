# Agent 协作指南

> 一句话：面向本仓库 AI 代理的协作约定——怎么干、写哪、分支保护。
> 源文档：[AGENTS.md](../../AGENTS.md)

## 现状

- 常驻命令集：项目速览、常用命令表、文档职责总表、全局约束（隐私/调试方法论）、分支保护。
- `main` 分支保护：任何改动必须走 PR，禁直推；合并前置门禁 = `typecheck` + 214 例测试（`strict: true`，约束 admin）。
- AI 开工顺序：读 AGENTS → 文档总表 → 相关文档 → 本机日志；重大变更（结构/行为大改、需决策留痕）建议开提案。
- 隐私硬规则：落盘前脱敏（相对路径、`<用户名>` 等占位符），与 `docs/` 同标准。

## 本文档不包括什么

- 直推 `main`（含 refspec 绕过法，会被 `GH006` 拒）。
- 把 E2E 设成 required status check（PR 上永远不上报，会卡死合并不了）。

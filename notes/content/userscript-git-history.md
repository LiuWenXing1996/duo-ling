# 脚本 Git 历史浏览

> 一句话：每脚本一仓、状态库权威 git 为历史侧车，保存自动版本、一键恢复（整树物化 + 新提交）。

## 现状

- 已实施（2026-09-14）：复用工具版本管理体系，落 offscreen 单写方同一处完成（写状态库 + git 提交同函数）。
- 每脚本一仓 `/uscripts/<uuid>/`；提交 = `project.json` + `files/*`，不提交 `bundle`（可派生产物）；`commitIfChanged` 无变更不产生空提交。
- 提交 message：备注优先，空则自动计数（`保存 #n`）；删脚本即删整目录仓（不做回收、不做备份）。
- 恢复 = 整树物化 + 新提交，绝不 reset/checkout（回错可再回，历史不可变）；浏览/恢复走 `ai:*` 命令（offscreen 应答）。

## 本文档不包括什么

- 已弃用旧 GM 记录的历史：升级后旧 `us:script:*` 只当已弃用记录展示、可一键清理，不在本体系追溯。
- 删脚本保留历史：删即删整仓、不回收；误操作由 confirm 拦截，本笔记不覆盖。

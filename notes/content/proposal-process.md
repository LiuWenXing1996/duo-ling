# 提案流程规范

> 一句话：可选工具（决策留痕非门禁）；五态状态机 + 流转记录 + 不可删；文档自包含。
> 源文档：[docs/proposal-process.md](../../docs/proposal-process.md)

## 现状

- 提案是可选工具（2026-09-17 降级）：日常改动直接做不开提案；重大变更建议开（决策留痕）；拿不准倾向不开。
- 已开提案规矩不变：五态（草稿/评审中/实施中/实施完成/拒绝）、目录即状态、流转记录只增不减、不可删、`npm run check:proposals` 校验。
- 文档自包含（不外链）；结构含问题/方案/备选方案/验收标准/不做的事/决策记录/流转记录。
- 决策记录必填（只增不减）；流转记录创建首条 = 新提案 → 草稿。

## 本文档不包括什么

- 直推 main（见 AGENTS 分支保护）；删提案/改历史流转记录；PR 装不下时拆 PR 不拆提案。
